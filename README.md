# 🎮 Modern Hangman Game

A modern and interactive Hangman Game built using **HTML**, **CSS**, and **JavaScript** with a stylish dark-themed user interface and smooth gameplay experience.

This project was developed as part of an internship task to demonstrate frontend development skills, JavaScript game logic, and responsive UI design.

---

## 🚀 Features

- 🎯 Random word generation
- 🌙 Modern dark-themed UI
- ✨ Glowing animated buttons
- ⌨️ Interactive keyboard system
- ❤️ Remaining attempts counter
- 🎉 Win and Lose messages
- 🔄 Restart game functionality
- 📱 Responsive design for different screen sizes

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
